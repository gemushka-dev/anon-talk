# AnonTalk

A high-performance, real-time anonymous chat application built with WebSockets. This project features a custom matchmaking system that pairs strangers based on availability.

## Features

- **Real-time Matchmaking:** Smart queue system that pairs users instantly.
- **Zero Data Retention:** Messages are never stored; they exist only in memory during the session.
- **Responsive UI:** Fully optimized for mobile, tablet, and desktop.

## Tech Stack

- **Frontend:** React + TypeScript
- **Backend:** Node.js + WebSocket + TypeScript

## Key Node Modules

- **Backend:** `ws`, `ts-node-dev`
- **Frontend:** `react`, `react-dom`, `typescript`

## Setup Instructions

### 1. Backend

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### 2. Frontend

1. Navigate to the frontend directory:
   ```bash
   cd ../frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm run dev
   ```
